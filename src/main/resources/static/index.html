Справка

Система учёта задач — программа для ведения реестра фоновых и регламентных заданий организации.

В разделе Задачи отображается таблица заданий. Выберите строку щелчком мыши. Панель инструментов позволяет создать, прервать или удалить задачу.

В разделе Исполнители — справочник сотрудников, которым могут быть поручены задачи.

В разделе Логи — общий журнал записей по всем задачам. Для просмотра лога одной задачи можно также дважды щёлкнуть по строке в таблице задач.

В разделе Типы задач — справочник всех поддерживаемых типов с описанием параметров и примерами.

В разделе Планировщик — расписание автоматического создания задач. Укажите тип, время первого запуска и при необходимости интервал повтора. В нужный момент планировщик создаёт задачу со статусом «Ожидает», и её подхватывает исполнитель.
