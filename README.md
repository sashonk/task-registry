# Task Registry

Система учёта фоновых и регламентных задач: очередь, исполнители-воркеры, планировщик, журнал и веб-интерфейс.

## Возможности

- **Задачи** — создание, выполнение, прерывание. Типы: расчёт, задержка, случайное число, преобразование текста, хеш, HTTP, проверка файла, SQL, отчёт, очистка, пакет, симуляция, Groovy-скрипт.
- **Исполнители** — фоновые воркеры забирают задачи со статусом «Ожидает». Добавить можно в любой момент; удалить — только исполнителя, у которого ещё не было задач.
- **Планировщик** — разовые и периодические расписания.
- **Логи** — общий журнал и лог одной задачи (двойной щелчок по строке).
- **Роли** — `ADMIN` управляет системой, `VIEWER` только просматривает.

## Требования

- JDK 17+
- Maven 3.9+

## Запуск

```bash
mvn package
java -jar target/task-0.0.1-SNAPSHOT.jar
```

Или:

```bash
mvn spring-boot:run
```

- Приложение: http://localhost:8080
- H2 Console (только `ADMIN`): http://localhost:8080/h2-console

JDBC URL: `jdbc:h2:file:./data/taskdb`

### Учётные записи по умолчанию

| Логин | Пароль | Роль   |
|-------|--------|--------|
| admin | admin  | ADMIN  |
| user  | user   | VIEWER |

Смените пароли, если приложение доступно не только локально.

## Стек

- Java 17, Spring Boot 4.1 (Web MVC, Security, Data JPA)
- H2 (файловая БД в `./data/taskdb`)
- Статический UI: HTML / CSS / JS
